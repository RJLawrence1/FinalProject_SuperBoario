# FinalProject\_SuperBoario



The objective of our game is that the player will control Boario. On a mission to get their villages' riches back from the evil Bearon. This will involve traversing through levels towards a main goal, but having opportunities for the player to explore for extra collectibles, which would lead to a different narrative ending.



We could not include boss fights, extra levels over the required amount, powerups, and destroyable game objects.



Given more time we would like to have added these and taken the time to polish our work. We think we could cut down on the number of scripts used throughout this project if we started from scratch with a clearer vision of how the game would come together. That said we stand by the final product and know that any of us could improve the game given more time.
